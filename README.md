# 启动台

启动台（原 Launch）是一个原生 macOS 全屏应用启动器，目标是在 macOS 26 Tahoe 上找回旧版“启动台”的使用方式。

它使用 Swift、SwiftUI 与 AppKit 编写，没有第三方依赖。界面会跟随系统的中英文首选语言。

## 1.12.1 改名与系统手势兼容

1. 应用显示名称、菜单、设置和安装包改为“启动台”；Bundle ID、内部可执行文件名与原有数据目录保持稳定。
2. 修复 macOS 26.6.2 上触控框架升级到 9460.1 后，全局五指监听因旧版本限制而停用的问题；新增支持限 Apple Silicon。
3. 未适配的系统版本会在设置中显示明确说明。接口检查与实机验收边界见 [五指手势兼容性记录](docs/multitouch-compatibility.md)。

当前 1.12.1 已通过自动检查及用户在 15 寸屏幕上的使用验证。13 寸屏幕适配暂缓，尚未完成对应实机验证。

## 1.12.0 文件夹悬停展开与开源收口

1. 把应用拖到现有文件夹并短暂停留后，文件夹会在同一次拖拽中自动展开；可直接把图标插入某个成员之前或拖到末尾，松手只执行一次原子保存，完成后文件夹保持打开。
2. 大文件夹在拖拽接近面板顶端或底端时会自动滚动；离开、取消、失焦或外部布局变化都会撤销临时预览，不会误提交旧落点。
3. 扫描器现在识别兼容的 iPhone/iPad 应用在 Apple-Silicon Mac 上使用的 `Wrapper/*.app` 包装结构；普通应用更新期间若基础 `Info.plist` 暂时不可读，则保留现有布局快照，不再把合法包装或更新中的应用误判为已卸载。
4. 修复全局快捷键冲突回滚与启动偏好竞态；已停用的菜单栏图标或快捷键不会在启动瞬间短暂恢复默认值。
5. 收紧五指延迟显示、原始触控启动失败、静默后备、鼠标拖拽隔离、设置窗口层级和退出流程，避免迟到任务抢焦或回调生命周期竞态。
6. 项目现以标准 MIT License 开源，并加入贡献说明、安全说明、AI 维护指南、兼容 SDK 自动探测和独立源码打包脚本。

## 1.11.1 拖拽隔离与双开角标优化

1. 拖拽应用时会硬隔离二指分页：主按键按下后，即使掌缘或另一根手指碰到触控板，也不会启动页面滑动；松开后仍会等本次触点全部离开才重新允许分页。
2. 微信双开角标保持约 20% 大小，改为暖金渐变、轻微内高光和连续双环标志；标准 ICNS、原微信图标大小与透明边界继续保持不变。

## 1.11.0 二指分页与界面收口

1. Launch 内的分页改为严格二指横滑；三指及更多触点会从出现到全部抬起整段忽略，纵向滑动与捏合也不会误触分页。连续跟手、距离提交与快速甩动仍然保留。
2. 五指合拢识别成功后会等待触点全部抬起，先激活 Launch，再延迟 120 毫秒显示窗口，给 macOS 的 App Exposé 浮层留出退场时间，避免应用名称叠在 Launch 的页点上。
3. 刘海屏的搜索框净距进一步增加；设置按钮与搜索框统一使用相同的薄毛玻璃、暗色着色、描边和阴影。
4. 右键菜单把“从 Launch 中隐藏”精简为带 `eye.slash` 图标的“隐藏”，与带废纸篓图标的“卸载”保持一致。
5. 微信双开版的 MIUI 橙黄色双环角标由 13% 调整为约 16%，仍保留原微信图标尺寸、透明边界和标准多分辨率 ICNS。

## 1.10.0 图标、菜单与刘海适配

1. “微信双开版”改用 MIUI 风格的左下角橙黄色角标，并以两个轻巧圆环表达双开。图标会生成标准多分辨率 ICNS，主图保持原有尺寸与透明边界，不再出现灰框或数字 `2`。
2. 主微信的右键菜单使用简洁的“**双开**”文案；确认后仍执行原有的事务式重建、签名、验证、替换与失败回滚流程。
3. 应用右键菜单移除“打开”和“编辑应用”。普通用户应用可选择“卸载”，随后进入共用的“移到废纸篓”确认；受系统保护的应用不会显示该项。
4. 顶部搜索与操作区域会按当前屏幕的刘海、安全区域和辅助顶部区域增加间距，同时保持搜索框的光学居中；普通屏幕继续使用原有紧凑间距。

## 1.9.0 实时应用管理与安全微信双开

1. 修复“管理应用”在搜索中切换显示或隐藏后，原生开关、状态文字和数量偶尔停留在旧状态的问题。开关会先即时更新，再安全提交并迁移分组；同一窗口内连续隐藏、恢复无需重新打开。
2. 同名应用仍优先保留应用自身的中文名，并使用应用提供的备用名称区分。当前主微信显示为“微信”，重建的副本显示为“微信双开版”。
3. 文件夹缩略图继续使用轻薄毛玻璃，同时在 2×2 或 3×3 小图标矩阵四周保留更清楚的留白，不再显得贴边或有厚重灰底。
4. 这一版把主微信右键菜单改为“创建或更新微信双开版…”，并加入从当前 `/Applications/WeChat.app` 开始的事务式重建；1.10.0 已将菜单文案精简为“**双开**”，重建、签名、验证、替换与失败回滚语义保持不变。

## 1.8.0 应用管理、文件夹与微信双开

1. 这一版首次让“管理应用”的搜索结果、分组与开关读取同一份模型状态；1.9.0 进一步修复了原生开关复用造成的实机显示滞后。
2. 应用名称继续优先使用首选语言的本地化名称；只有出现真实同名冲突时，才使用应用自身的其他名称或包目录名区分。当时的现有副本显示为“微信生活版”。
3. 未打开的文件夹缩略图加入轻薄毛玻璃、微渐变和发丝描边，并为“减少透明度”提供实色兜底。
4. 当时的“双开微信”菜单只会打开已存在且 Bundle ID 精确匹配的“微信生活版”；1.9.0 已由每次事务式重建取代这一旧流程。

## 1.7.1 三指实机修复与默认大图标

1. 根据真实触控板日志修复三指页面已经明显跟手、却在不均匀抬指时偶尔回弹的问题：抬手尾帧的触点身份或间距波动不再取消有效翻页。
2. 三指底层通道接管后会隔离迟到的系统触控尾段，避免同一次手势被重复识别；二指仍不会进入分页路径。
3. 新配置的默认图标大小改为 100 pt；已有用户保存的图标大小保持不变，布局会继续为标题、页点和程序坞保留安全距离。
4. 内容未溢出的页面会关闭纵向滚动与回弹，避免二指操作产生类似分页的视觉位移；极端小屏幕仍保留必要的纵向滚动。

## 1.7.0 手势与交互改进

1. 三指分页增加 45 毫秒底层触控优先仲裁，避免页面已经跟手后又被 macOS 系统手势取消；翻页改为明确的距离优先和同向快滑规则。
2. 只有水平意图明确的三指手势才会进入分页，上下三指与垂直为主的斜滑不会移动页面。
3. 底部页点每页都有 44×44 pt 独立点击范围，更容易选页且不会相互重叠。
4. 应用管理仍是一个列表，但会按“可见”和“已隐藏”分组，组内按本地化名称排序。
5. 移到废纸篓的确认界面已精简；错误警示条会在 4.6 秒后自动消失，新错误不会被旧计时器误清除。
6. 拖拽时顶部显示“取消”投放区，松手只取消当次拖拽，不会改动布局。
7. Launch 主窗口被其他软件抢走焦点时会自动关闭；设置和系统确认框等自有流程不会误触发。

## 1.6.2 触控与界面修复

1. 修正 macOS 26.5.2 原始触点记录的稳定身份字段，避免三指被误判为重复触点而丢弃整帧。
2. 原始触控与 AppKit 本地触控改为单一来源仲裁：私有触控桥静默时不再禁用本地三指后备，同时不会重复翻页。
3. 搜索框根据当前屏幕的刘海、安全区域和侧边 Dock 计算光学中心，齿轮保持紧邻但不再拉偏搜索框。
4. 编辑模式改为叶子图标独立的低频共享抖动时钟，不再每帧重建整页网格；错误警示条也会动态避让底部或侧边 Dock。

## 1.6.1 交互稳定性修复

1. 修复三指页面已跟手移动，松手却回弹的问题：足够的实际位移优先决定翻页，松手尾段的一指或二指不再改写结果。
2. 拖拽坐标恢复为鼠标与图标严格 1:1 跟手，取消会让两者越拖越远的位移增益。
3. 编辑模式下可以正常打开文件夹并管理其中的应用。
4. 将应用从文件夹拖向主网格时，文件夹面板会临时淡出；取消、拖回或放置失败时会恢复。
5. 大图标会压缩额外行列间距，同时为图标、双行标题和 Dock 保留完整空间；极端设置使用内部滚动兜底。

## 1.6.0 拖放、触控与布局改进

1. 拖动排序不再显示白色插入线，改用图标实时让位与轻微缩放预览。
2. 文件夹成员可以直接拖回主网格、其他页面或另一个文件夹；文件夹只剩一个成员时会自动解散。
3. 文件夹缩略图和展开面板已简化，去掉多余灰底、分隔和装饰层。
4. 拖动使用更灵敏的 5 pt 启动距离与 1.2 倍温和位移增益，触控板无需滑动过远。
5. 拖入文件夹的中心命中范围更大，等待时间缩短到 120 毫秒。
6. 显示与隐藏应用合并到同一个可搜索“应用列表”，每一项可直接切换状态。
7. 设置按钮移动到搜索框旁边。
8. Launch 显示时会遮住当前屏幕顶部菜单栏与状态图标，但不会修改或遮挡程序坞。
9. 分页事件链仅接受精确三指；一指、二指和四指以上都不会翻页。
10. 快速三指短滑会结合位移与速度完成翻页，不再因为手势太快而丢失。
11. 五指合拢加入逐根落指历史、短暂掉点容错与动态阈值，提高打开成功率。
12. 页面圆点、应用图标和名称会按当前屏幕的可见程序坞位置动态留出安全距离。

## 主要功能

- 全屏应用网格、搜索与多页浏览
- 实时预排的同页、跨页拖动排序，以及文件夹创建、加入、成员排序和成员拖出
- 拖到文件夹后自动展开，可在同一次拖拽中精确选择文件夹内位置
- 优先显示应用自带的中文本地化名称
- 监听应用程序目录，新安装或移除应用后自动刷新
- 编辑模式可直接隐藏应用，并可在设置的统一应用列表中恢复
- 设置中可搜索所有应用并直接切换显示或隐藏状态，开关、说明与数量实时同步
- 长按后立即进入编辑模式；每个应用都有隐藏按钮，可卸载应用另有移到废纸篓按钮，松手不会误启动
- 默认使用 `⌥ Space` 显示或隐藏，也可在设置中更改或停用
- 五指捏合显示/隐藏，Launch 内二指连续横滑翻页
- 普通模式点击图标之间的空白处即可关闭 Launch；编辑模式下只退出编辑
- 方向键翻页、`Return` 打开应用、`Esc` 隐藏
- 可选菜单栏图标与开机启动选项
- 右键主微信并选择“**双开**”，可从当前主包事务式创建或更新带角标的“微信双开版”
- 行列数、图标大小、名称显示等布局设置
- 自动保存布局与偏好

## 安装与使用

打开发布的 DMG，把 `启动台.app` 拖入“应用程序”文件夹，然后运行启动台。完整说明见 [使用说明.md](./使用说明.md)。

启动台内的分页只识别精确二指横滑，三指及更多触点不会进入分页状态，因此 Mission Control、App Exposé 与 Spaces 的三指手势继续交给 macOS。五指合拢被识别后会在下一次主线程调度时请求显示窗口；启动台不会拦截系统手势、重启程序坞或永久修改系统偏好。全局五指识别在不兼容时会使用严格五触点的尽力后备路径；仍不可用时，可使用已配置的全局快捷键、菜单栏图标或从“应用程序”文件夹打开启动台。

## 构建

在本目录运行：

```sh
./scripts/run-tests.sh
./scripts/package-dmg.sh
./scripts/package-source.sh
```

脚本会运行完整检查，并生成 `dist/启动台.app`、经过校验的 `dist/启动台-1.12.1.dmg` 与不含构建缓存的 `dist/启动台-1.12.1-source.zip`。当前脚本执行本机临时签名，适合个人使用；向其他 Mac 正式分发时，需要 Apple Developer ID 签名与公证。

## 已知边界

- 应用浏览、搜索、选择和启动支持键盘，但创建文件夹、重排及移入/移出文件夹目前仍需要鼠标或触控板拖拽，尚无完整的 VoiceOver/纯键盘等价整理流程。
- 全局五指路径包含按系统构建严格限制的私有 MultitouchSupport 后备，因此当前实现不适合提交 Mac App Store；系统升级后会安全降级，但仍需在真实硬件上验证。
- 仓库脚本生成的是临时签名本地包。公开分发二进制前，维护者仍需完成 Developer ID 签名与 Apple 公证。

## 系统要求
